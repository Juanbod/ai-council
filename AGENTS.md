# AGENTS.md — общие правила для ИИ-разработчиков проекта

Этот файл читают оба участника разработки: **Codex** (читает `AGENTS.md` автоматически) и **Claude Code**
(через `CLAUDE.md`, который импортирует этот файл). Владелец проекта — человек-«председатель»;
решения о направлении принимает он.

## Что это за проект

«Совет ИИ» — терминальное приложение (Python + Textual). Пользователь создаёт заседания с темой, прикрепляет
файлы и задаёт вопрос; Claude Code CLI и Codex CLI сначала независимо анализируют задачу, затем спорят
раундами, пока оба не примут **один и тот же** зафиксированный вариант ответа.

## Структура

| Файл | Ответственность |
|---|---|
| `council/store.py` | Заседания на диске: `sessions/<id>/meta.json`, `events.jsonl` (append-only протокол), `files/` (копии вложений) |
| `council/agents.py` | Вызов CLI (`ClaudeAgent`, `CodexAgent`), `MockAgent` для тестов, JSON-схема ответа, `extract_json` |
| `council/engine.py` | Протокол дебатов `Debate`: промпт, раунды, голосование, восстановление из протокола |
| `council/app.py` | Интерфейс Textual: список заседаний, лента, ввод, команды, фоновые обсуждения |
| `tests/` | `test_engine.py` — протокол на фиктивных агентах; `test_app.py` — интерфейс через `App.run_test` |
| `config.json` | Локальные настройки (пути к CLI, модели, таймауты). Создаётся при первом запуске, в git не хранится |

## Инварианты протокола — НЕ ломать

Любое изменение движка должно сохранять эти свойства:

1. **Слепой раунд 0.** В раунде 0 ни один участник не видит позиции и кандидатов другого.
2. **Симметрия.** Состояние раунда (тема, список вложений, протокол, кандидаты) читается **один раз**
   (`Debate._snapshot`) и одинаково для обоих; вызовы параллельны; ответы добавляются в протокол только после
   завершения *обоих*. Изменения председателя во время раунда попадают в следующий снимок.
3. **Консенсус = один id.** Кандидаты неизменяемы, `id = sha256(text)[:8]`. Консенсус — только если оба в одном
   раунде (≥ 1) проголосовали `ACCEPT` за один и тот же id, уже существовавший до этого раунда.
4. **Сбой ≠ согласие.** Невалидный JSON → один повтор с текстом ошибки; повторный сбой → голос `REJECT`.
5. **Только чтение.** Агенты не изменяют файлы: Codex `--sandbox read-only`, Claude
   `--disallowedTools Edit,Write,NotebookEdit,Bash,WebFetch`.
6. **Без `shell=True`.** Исполняемые файлы находятся через `shutil.which`; промпт передаётся через **stdin**
   (обход лимита длины командной строки Windows ~32К).
7. **Протокол append-only.** `events.jsonl` только дописывается; `Debate.from_events` восстанавливает обсуждение
   для `/continue` после перезапуска, учитывая **только завершённые пары** ответов (оборванный раунд переигрывается).

Сопутствующие правила: один экземпляр `Session` на id (`Store` кэширует), `Session.set` — чтение-изменение-запись
под замком; повторный запуск того же `Debate` (`/continue` после `/stop`) сбрасывает `cancel` до старта потока.

## Проверенные факты об окружении (2026-11-02, Windows 11)

- Python 3.12.10, Textual 8.2.8, jsonschema, pytest, pytest-asyncio.
- **Codex CLI 0.166.0**: `codex exec` принимает промпт из stdin при аргументе `-`; работают `--output-schema <file>`,
  `-o/--output-last-message <file>`, `--sandbox read-only`, `-C <dir>`, `--skip-git-repo-check`, `--ephemeral`,
  `-i <image>`. Модель по умолчанию берётся из `~/.codex/config.toml` (`gpt-6.1-sol`), поэтому `model` в
  `config.json` пустой. Структурированный вывод OpenAI требует строгой схемы: все поля в `required`,
  `additionalProperties: false`.
- **Claude Code CLI 2.1.316** (npm `@anthropic-ai/claude-code`), вход через `claude auth login`:
  `-p --output-format json` возвращает объект с `result`, при `--json-schema` — ещё и `structured_output`.
  `--disallowedTools`, `--model` есть.
- Живой тест: полный спор по `dedupe.py` дошёл до консенсуса за 1 раунд (~35 с).

## Как запускать и проверять

```
pip install -r requirements.txt
python -m pytest -q tests          # должно быть: 28 passed (на момент 2026-11-02)
.\run.bat --mock                   # интерфейс на фиктивных агентах, без затрат
.\run.bat                          # настоящие Claude и Codex
```

`--mock stubborn,agree` задаёт поведение фиктивных агентов: `agree`, `stubborn`, `flaky` (первый ответ битый), `slow`.
Тесты не должны вызывать настоящие CLI.

## Соглашения

- Интерфейс, промпты, комментарии и сообщения — **на русском**. Код и идентификаторы — на английском.
- Стиль: короткие функции, комментарии только там, где неочевидно «почему». Без новых зависимостей без причины.
- Любое изменение протокола → тест на новое поведение + проверка, что инварианты выше по-прежнему покрыты.
- Пользовательские данные (`sessions/`) и `config.json` в git не попадают.

## Как работаем вдвоём (Claude + Codex)

- **Один пишущий за раз.** Каждая задача — отдельная ветка (`claude/<задача>` или `codex/<задача>`).
  Не правьте файлы, которые в этот момент меняет другой агент.
- **Перекрёстное ревью.** Автор открывает изменение, второй агент проверяет diff: корректность, инварианты,
  тесты. Замечания — конкретные: файл:строка, сценарий сбоя, предложенное исправление.
- **Несогласие** решается так же, как в самом продукте: аргументы → встречное предложение → итог согласует
  председатель. Решения записывайте в раздел «Журнал решений» ниже (кратко: дата, решение, почему).
- Перед завершением любой задачи: `python -m pytest -q tests` зелёный.

## Известные ограничения и бэклог

- **Угодливость**: участники могут соглашаться слишком быстро. Идеи: запрет `ACCEPT` в раунде 1,
  роль «адвоката дьявола», требование явного аргумента для уступки.
- **Рост контекста**: раунды старше двух последних сжимаются обрезкой (`_compact_log`), а не настоящим резюме.
- **Нет прогресса внутри вызова**: пока агент думает (десятки секунд), лента не обновляется; можно перейти на
  `--output-format stream-json` / `codex exec --json`.
- **Нет учёта стоимости/токенов** и времени по раундам.
- Поле `rounds` в вердикте без консенсуса равно `max_rounds + 1` (номер следующего раунда) — стоит уточнить семантику.
- `CouncilApp._agents_info` пересоздаёт агентов при каждой отрисовке реплики — мелкая неэффективность.
- Изображения передаются явно только Codex (`-i`); Claude читает их сам инструментом Read.
- Протокол рассчитан ровно на двух участников.
- Изоляция Claude держится на запрете инструментов, а не на песочнице ОС.
