# Совет ИИ: Claude × Codex

Терминальное приложение: вы назначаете заседание и его тему, прикрепляете файлы и задаёте вопрос.
Claude и Codex сначала независимо анализируют задачу, затем спорят, пока оба не примут **один и тот же**
зафиксированный вариант ответа (или пока не кончится лимит раундов).

## Запуск

```
pip install -r requirements.txt
.\run.bat              # настоящие агенты
.\run.bat --mock       # фиктивные агенты, без затрат — посмотреть интерфейс
```

В PowerShell обязателен префикс `.\` и запуск из папки проекта.
Для разработчиков-ИИ (Claude и Codex) правила проекта — в `AGENTS.md`, промпт для ревью — в `docs/codex-review-prompt.md`.

Нужны установленные и авторизованные CLI: `codex` (Codex CLI) и `claude` (Claude Code CLI:
`npm install -g @anthropic-ai/claude-code`, затем один раз `claude` для входа).
Пути, модели и таймауты — в `config.json` (создаётся при первом запуске). Пустая `model` у Codex
означает модель из `~/.codex/config.toml`.

## Интерфейс

- Слева — список заседаний (⏳ идёт, ✅ консенсус, ⚖️ без консенсуса, ⏹ остановлено). Обсуждения идут в фоне,
  можно переключаться между заседаниями (клик, Ctrl+PgUp/PgDn).
- Текст в строке ввода — вопрос совету. Во время спора — реплика председателя, учитывается в следующем раунде.
- Файлы: перетащите в окно терминала и нажмите Enter, либо Ctrl+O, либо `/attach путь`.
  Файлы копируются в папку заседания `files/`; агенты читают их, но ничего не меняют.
- F1 — список команд (`/new`, `/topic`, `/rounds`, `/stop`, `/continue`, `/export`…).

## Протокол

1. Раунд 0 — слепой анализ: оба вызываются параллельно и не видят друг друга.
2. Каждый раунд оба получают **один и тот же снимок** состояния; ответы добавляются только после пары вызовов.
3. Варианты итога неизменяемы, id = хеш текста. Консенсус — оба в одном раунде проголосовали `ACCEPT` за один id.
4. Ответ проверяется по JSON-схеме; при ошибке — повтор, при повторном сбое голос считается `REJECT`.
5. 🥚 **Яйца, как в Верховной Раде.** У каждого ИИ на обсуждение 3 яйца — знак крайнего несогласия
   (поле `egg` в ответе). Яйцо срывает голосование: в раунде, где оно летело, консенсус не засчитывается.
   В слепом раунде 0 бросать не в кого. Счёт яиц — в вердикте и в `/export`.
   Посмотреть без затрат: `.un.bat --mock hothead,agree`.

Данные: `sessions/<id>/` — `meta.json`, `events.jsonl` (полный протокол), `files/`, `protocol.md` после `/export`.
