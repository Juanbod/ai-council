# Промпт для ревью проекта Codex-ом

Запуск из папки проекта (интерактивно): `codex`, затем вставить текст ниже.
Или без интерактива (PowerShell):
`Get-Content docs\codex-review-prompt.md -Raw -Encoding UTF8 | codex exec --sandbox read-only -`

---

Ты подключаешься к разработке проекта «Совет ИИ» вторым разработчиком (первый — Claude Code).
Сначала прочитай `AGENTS.md` целиком — там архитектура, инварианты протокола, проверенные факты о CLI,
соглашения и правила совместной работы. Потом `README.md` и весь код в `council/` и `tests/`.

Задача — независимое ревью, ничего не меняй в файлах:

1. Запусти `python -m pytest -q tests` и сообщи результат.
2. Проверь, что каждый из 7 инвариантов в `AGENTS.md` действительно соблюдается кодом и покрыт тестом.
   Если инвариант можно нарушить — опиши конкретный сценарий.
3. Найди ошибки корректности: гонки между потоком обсуждения и интерфейсом, обработка ошибок CLI,
   кодировки на Windows, восстановление `/continue` после перезапуска, работа с путями вложений.
4. Проверь вызовы `codex exec` в `council/agents.py` против фактического `codex exec --help` твоей версии.
5. Оцени раздел «Известные ограничения и бэклог»: что важнее всего сделать дальше и почему.

Формат ответа — список замечаний, от самых серьёзных:
- `файл:строка` — суть проблемы
- сценарий сбоя (входные данные / состояние → что пойдёт не так)
- предлагаемое исправление
- уверенность: высокая / средняя / низкая

В конце — 3 приоритетные задачи на следующий шаг. Замечания с которыми ты не уверен, помечай явно;
Claude ответит на них, а спорные пункты решит председатель.
